# 2026-07-25 — Sesi 02

Sesi pertama dengan izin tulis GitHub aktif. Dari nol menjadi universe
point-in-time terverifikasi dalam satu putaran.

## Yang dibangun

Repo `EnVyxS/lux-research` dibuat, `STATE.md` sebagai jurnal tunggal, workflow
`doctor` untuk mengukur runner, dan `lux/universe.py` untuk membangun universe
dari arsip.

## Pemecahan masalah terpenting sesi ini

Agen tidak punya kemampuan membaca log workflow. Awalnya ini diperlakukan
sebagai batasan permanen yang mengharuskan pengguna menyalin log secara manual.
Solusinya ternyata sederhana: **setiap workflow menulis hasilnya ke `reports/`
dan meng-commit balik ke repo.** Agen membaca berkas itu lewat API biasa.

Ini menghapus pengguna dari jalur kritis sepenuhnya. Pola ini sekarang wajib
untuk setiap workflow baru.

## Kesalahan yang tercatat

1. Menyimpan unduhan sebagai `probe.zip` sementara berkas `.CHECKSUM` merujuk
   nama asli. Terbaca sebagai `checksum_ok: false`, seolah data rusak. Murni
   bug penamaan. Diperbaiki, checksum kini cocok.
2. Memperkirakan disk runner 14 GB. Meleset enam kali lipat. Pelajarannya bukan
   soal angka, melainkan bahwa perkiraan tidak boleh masuk perencanaan tanpa
   diukur lebih dulu.
