# 2026-07-25 — Sesi 01

Sesi pertama yang tercatat di repo. Sebelumnya seluruh riwayat ada di Notion.

## Yang terjadi

**Clean slate.** Pengguna memutuskan membangun ulang dari nol tanpa membawa bias dari upaya sebelumnya, termasuk log sinyal bot v8.4. Tiga puluh tiga halaman Notion dihapus untuk mencegah kontaminasi. Pelajaran metodologis diekstraksi ke satu halaman ringkas sebelum penghapusan.

**Pencarian tempat komputasi.** Berurutan: sandbox agen gugur karena tidak punya jaringan sama sekali. Oracle Cloud gugur karena butuh kartu kredit. Cloudflare R2 layak untuk penyimpanan tapi tidak menyediakan komputasi. Akhirnya pengguna menunjuk GitHub Actions, yang ternyata pilihan terbaik: menit tak terbatas untuk repo publik.

**Pivot arsitektur.** ADR-002 ditulis, menggantikan bagian penyimpanan pada ADR-001. Seluruh komputasi pindah ke Actions. Parquet disimpan sebagai aset GitHub Release, bukan di dalam git.

**Koreksi yang saya buat terhadap diri sendiri.** Saya sempat merekomendasikan pemisahan repo publik dan privat, dengan alasan menjaga kerahasiaan strategi. Rekomendasi itu cacat: bagian yang paling haus menit komputasi justru pencarian parameter strategi, yaitu bagian yang ingin diprivatkan. Kuota 2.000 menit per bulan untuk repo privat setara 33 jam, jauh dari cukup. Direvisi menjadi satu repo publik.

**Agen pengawas.** Database Run Results dan agen LUX Gatekeeper dibangun dan diuji. Pengujian dengan baris bercacat sintetis lulus.

**Izin GitHub.** `create_repository` ditolak 403 sebanyak dua kali sebelum pengguna memperluas izin token. Percobaan ketiga pukul 20.48 WIB berhasil.

1. Saya menyebut path `data.binance.vision/futures/um/...` tanpa prefix `data/`. Pengguna mengoreksi dengan tangkapan layar galat `NoSuchKey`.
2. Saya berasumsi dataset 5m–4h sudah tersedia secara fisik. Ternyata hanya tercatat di dokumen; secara fisik hanya ~47 MB yang persisten.
3. Saya sempat mengklaim tidak bisa menjadi agen latar belakang. Salah — Notion menyediakan trigger. Saya koreksi sendiri setelah membaca dokumentasi trigger.
